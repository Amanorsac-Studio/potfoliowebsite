Codes

Make codes, hand them out, see what has been used. Nobody has to send you an email address and wait.

Make some

An access code gives somebody the app. How long for is decided here, per batch: leave the days box empty and it is theirs to keep, put 30 in it and their licence ends thirty days after they redeem it. A discount code takes money off at checkout instead.

1 = one person per code
empty = theirs to keep
empty = never

Every code

Switching one off stops it working immediately, and does not touch anything already redeemed with it.

Redeemed

Codes are checked on the database, never in a browser, and a code with uses left is spent while its row is held — two people racing for the last use of a code cannot both win.
