# AETHER demo clips

The A/B players on the AETHER page look for these eight files. Each pair
is the same passage: one bypassed, one through the plugin.

    vocal-off.mp3   /  vocal-on.mp3    lead vocal, close-mic
    choir-off.mp3   /  choir-on.mp3    choir, wide room pair
    piano-off.mp3   /  piano-on.mp3    piano, room recording
    mix-off.mp3     /  mix-on.mp3      full mix, two-bus

Until a pair is here, its card says so rather than presenting a player
that does nothing.

## What matters about how they are recorded

**Match the level.** The page says the pairs are RMS-matched, and an
audience that can hear the difference between louder and better will
check. Bounce the "on" version with Auto Gain engaged, then measure
both and correct any remaining difference. If "on" is simply louder,
the whole page loses the people it was written for.

**Keep them short.** Three to six seconds. The players hold both files
in memory and play them together so the switch is instant, which means
every clip is downloaded before anything is heard.

**Same passage, same bounce settings, same everything else.** No other
processing on either side.

MP3, 192 kbps or better, mono or stereo as the source demands.
