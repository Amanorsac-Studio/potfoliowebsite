# Drop pictures here

This is the folder to put app pictures in. Copy them in, run
`send-pictures.bat` in the main folder, and tell me they are here.

    C:\Users\amano\potfoliowebsite\images\incoming\

## Naming

Start every file with the app's name, then what the picture is. Lower
case, hyphens instead of spaces, and the extension your screenshot tool
gave it.

    aether-ui.png
    aether-activation.png
    aether-about.png
    stemsorter-analyzed.png
    nebulatide2-shimmer.png

That is all I need to know where a picture belongs. If a name does not
say which app it is for, I have to ask, which costs us a round trip.

## What happens to them

Nothing is served from this folder — it is the loading bay, not the
shop. I take what you put here, convert it to the format the site uses,
size it for the page it is going on, and put it in `images/apps/<app>/`
with the rest.

So: originals here, and do not worry about the size or the format. A
4 MB PNG straight off the screen is exactly right.

## Screen shots that work well on a page

- **Full window, no desktop.** The window and nothing around it.
- **Something happening.** A meter moving, a curve drawn, a list with
  real names in it. An empty interface makes an empty page.
- **Real content.** A session called "Sunday Service 09-13" tells a
  truer story than "Untitled 1".
- **Dark or light, but say which.** Both is better if the app has both.

If you want a picture at a particular size for a particular spot, say
the spot and I will tell you the size to shoot.
